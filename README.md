# combinatory-types
Type inference for SK-combinators 

These are the Rocq proofs of the results in the paper "Simple Types for Polymorphic Functions" which is still being polished. 

Abstract: This paper introduces a simple type system for combinatory
logic in which combinators have at most one type, whose polymorphism
is revealed by application. The types are abstract types built on combi-
natory types. The combinatory types exactly describe the structure of
their values, which is hidden by abstract types. For example, function
types are abstract types. There is no type variable quantification. The
simplicity of the formalism makes static program analysis easier. For
example, the system provides natural support for type inference.
